# 验收清单

- [x] 应用首屏直接提供“学习方法”和“闯关练习”入口，无需登录即可使用
- [x] 首页展示累计星星、连续答对和四类题型的学习进度
- [x] 不进位加法题均满足结果不超过 100，且个位相加小于 10
- [x] 进位加法题均满足结果不超过 100，且个位相加大于或等于 10
- [x] 不退位减法题均满足结果不小于 0，且个位无需借位
- [x] 退位减法题均满足结果不小于 0，且个位需要借位
- [x] 四类题型均提供儿童可理解的分步方法讲解
- [x] 数位板正确展示十位、个位以及进位或借位过程
- [x] 讲解支持上一步、下一步和重新演示，步骤与最终结果一致
- [x] 练习支持四类单项练习和综合练习
- [x] 一轮练习展示总题数和当前进度，并在完成后展示总结
- [x] 仅接受 0 至 100 的整数答案，无效输入不会触发判题或计分
- [x] 点击提交和按 Enter 的行为一致
- [x] 正确答案更新连续答对和星星，且同一道题不会重复计分
- [x] 错误答案显示鼓励性提示和正确的分步解析
- [x] 练习总结展示正确题数、准确率、奖励和合理的复习建议
- [x] 连续答对里程碑提供不遮挡核心操作的庆祝反馈
- [x] 学习进度可在浏览器刷新或重新打开后恢复
- [x] 本地数据损坏、缺失或版本不兼容时应用安全回退且可继续使用
- [x] 在 320 像素宽手机视口及常见桌面视口中无水平溢出、遮挡或文字重叠
- [x] 所有交互控件可通过键盘访问，焦点清晰，名称可被辅助技术识别
- [x] 正误反馈不只依赖颜色，答题结果可通过状态区域被辅助技术感知
- [x] 启用 `prefers-reduced-motion` 后非必要动画关闭，完整功能仍可使用
- [x] 题目生成、答案校验、奖励计算和异常进度回退具有自动化测试覆盖
- [x] 关键桌面与手机流程通过浏览器验证，控制台无应用错误且页面非空白
- [x] 工作区仅保留代码和规格修改，不自动执行 Git commit 或 push
