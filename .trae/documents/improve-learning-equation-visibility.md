# 提升“学习方法”题目关联性的实施计划

## Summary

将完整示例题从页面标题右侧移入讲解卡片顶部，形成固定且高对比的“本题”栏；同时为步骤中的局部算式增加“这一步”标签，让儿童能够按“完整题目 → 当前步骤 → 数位板”的顺序理解计算过程。

## Current State Analysis

- 当前完整算式位于 `src/pages/LearnPage.tsx` 的 `.learn-header` 右侧，与下方 `.lesson-card` 存在明显空间距离。
- 进入步骤后，`.step-copy__equation` 仅展示当前局部计算，没有文字说明它与完整题目的关系。
- 桌面宽屏下标题和算式左右分布，视觉焦点被拆散；截图中完整算式尤其容易被误认为独立信息。
- 移动端现有媒体查询会将页头改为纵向，但完整算式仍在讲解卡片之外。

## Proposed Changes

### 1. 调整完整题目的信息位置

文件：`src/pages/LearnPage.tsx`

- 从 `.learn-header` 中移除现有 `.learn-equation`。
- 在题型标签之后、`.lesson-card` 内容顶部增加 `.lesson-equation-bar`。
- 题目栏包含：
  - 明确的“本题”标签。
  - 当前题型名称，例如“进位加法”。
  - 完整算式，例如 `28 + 17 = 45`。
- 保留现有动态数据来源，切换题型时题目栏同步更新。
- 保留完整的辅助技术描述，使用现有示例算式 `aria-label` 语义，不改变键盘交互。

### 2. 强化完整题目与当前步骤的关系

文件：`src/pages/LearnPage.tsx`

- 将 `.step-copy__equation` 从单独文本调整为带标签的局部算式区域。
- 增加“这一步”提示文字，明确局部算式是完整题目的当前拆解步骤。
- 不修改 `src/domain/lessons.ts` 的题目和步骤数据，不改变讲解逻辑、步骤数量或数位板行为。

### 3. 更新视觉层级与响应式布局

文件：`src/pages/LearnPage.css`

- 将 `.learn-header` 改为单列标题区域，减少右侧空置和视觉分散。
- 新增题目栏样式：
  - 使用高对比浅色背景、清晰边框和有限阴影。
  - 完整算式居中并使用比步骤标题更醒目的固定字号。
  - 答案使用现有主色强调，但不只依赖颜色表达。
- 调整 `.lesson-card` 顶部结构，使题目栏、课程概览、步骤进度自然连续。
- 为“这一步”局部算式增加较小标签，维持与完整题目的主次关系。
- 在现有 `52rem` 和 `34rem` 断点下调整内边距、字号及换行，确保 320px 宽度无水平溢出或遮挡。
- 延续现有圆角、色彩变量和 `prefers-reduced-motion` 行为，不增加新的动画。

## Assumptions & Decisions

- 采用用户确认的“卡片顶部固定栏”方案。
- “固定”指切换讲解步骤时题目栏始终保留在讲解卡片顶部，不实现滚动吸顶，避免遮挡页面导航。
- 完整算式仍展示答案，因为该页面用于方法讲解而非答题测验。
- 不修改首页、练习页、提示音、题目生成和本地进度逻辑。
- 不新增图片、音频或第三方依赖。
- 不执行生产 build、compile、git commit 或 push。

## Verification

1. 打开四类学习方法，确认切换题型后“本题”栏的完整算式、题型名称和答案同步正确。
2. 逐步点击“下一步”“上一步”“重新演示”，确认完整题目保持可见且局部算式正确标注为“这一步”。
3. 在桌面视口检查标题、题型标签、题目栏、步骤概览和数位板的视觉顺序连续。
4. 在 320px 手机视口检查题目栏和局部算式可完整换行，无水平溢出、裁切或文本重叠。
5. 使用键盘切换题型和步骤，确认焦点顺序与原有行为不变，辅助技术仍可读取完整示例算式。
6. 运行现有单元测试，确认教学页面调整未影响算题、计分和存储逻辑。
